# AI-Powered Web Flow Mapper

## Project Overview
This project is a Java-based AI-powered web flow mapper that crawls websites, discovers pages and forms, builds a navigation graph, exports crawl data as JSON, and generates an AI-based security analysis using Google's Gemini API.

## Technologies Used
- Java
- Java HttpClient
- Jsoup
- Jackson
- Graphviz
- Google Gemini API

## Generated Outputs
- Graphviz DOT file
- Navigation Graph PNG
- states.json
- transitions.json
- forms.json
- AI-generated analysis report

## Important Classes
- Main.java
- AIAnalysisService.java
- GeminiClient.java
- CoveragePrioritizer.java
- UnknownStateDetector.java
- SemanticMutationEngine.java
